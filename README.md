# Meu Emprego

**O próximo passo da sua carreira.**

Plataforma brasileira de oportunidades profissionais, conectando candidatos e empresas.

## Primeira etapa
Esta versão contém a identidade visual e a interface pública responsiva. As oportunidades exibidas são exemplos demonstrativos. Cadastro, autenticação, publicação de vagas e candidaturas reais serão integrados em etapas posteriores.

## Desenvolvimento
```bash
npm install
npm run dev
```

## Build
```bash
npm run build
```
